Entry for the make.fun competition [Two-Sentence Horror](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253).

## Why this line

Candidates: (A) a baby monitor singing in the narrator's voice, (B) the chosen mirror line, (C) scratching from inside the walls. B won against the judge brief: exactly two sentences, the second reframes the first (the mirror was not scaring the thing in the corner; it was letting it see the narrator), the horror is implied rather than explained, and it is not a familiar retold twist.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) validates the fixed entry line against the competition gate and writes it to `entry.txt` under `MAKEFUN_OUTPUT_DIR` (default `/output`), then reads the file back to verify the bytes.
